# docs/AGENTS.md

Index for the `no_time_to_die` (HERACLES) documentation hub. The documents
here are operational guidance for agents; the enforced gates live in
`pyproject.toml`, the test suite, and the code-review protocol in `AGENTS.md`.

- `agent_instructions.md` — behavioral rules (Read-first protocol).
- `architecture.md` — layer contract, per-module inventory, and the frozen
  bond-api MissionProvider mapping.
- `testing_philosophy.md` — zero-mock policy, coverage mechanics, and the
  "a gate must be able to fail" doctrine.

The package root `README.md` and `AGENTS.md` are the authoritative entry
points; `TODO.md` records built work and declared integration points.
